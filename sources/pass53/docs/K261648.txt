Device Description: 807.92(a)(4)
The Evident Vascular™ Guidance System (EVGS) is designed for ultrasound
examinations of intravascular pathology. The EVGS supplies diagnostic information
when used in conjunction with the Evident Peripheral Imaging Catheters during
intravascular ultrasound (IVUS) imaging of peripheral vasculature. It is designed to be
used as an adjunct to conventional angiographic procedures or endovascular therapy.

The system includes the workstation computer that is the main system controller and
runs dedicated software. A single-use, sterile intravascular ultrasound catheter
generates real-time IVUS images, which are displayed on a user interface tablet. The
Evident™ Tablet serves as the primary user interface image visualization and system
control. The Catheter Interface Module (CIM) provides the connection to the catheter. An
optional auxiliary display may be used with the workstation for additional image viewing,
depending on clinical preference.
The EVGS is available in both a mobile cart configuration and an integrated laboratory
configuration. Both configurations provide the same system functionality and user
interface capabilities, with differences limited to installation environment and system
layout.

Technological Characteristics: 807.92(a)(6)
The Evident Vascular™ Guidance System (EVGS) includes a Console featuring a
workstation, catheter interface module (CIM), tablet-based user interface, and single-use
intravascular ultrasound (IVUS) imaging catheters. The system is intended as an adjunct
to angiographic procedures or endovascular therapy for examination of intravascular
pathology EVGS provides real-time intravascular ultrasound imaging of the peripheral
vasculature.
The EVGS and the predicate device share the same fundamental IVUS imaging
modality and intended diagnostic purpose of intravascular ultrasound imaging.
 Both systems are available in integrated and mobile configurations and provide
comparable imaging functionality. Each system complies with applicable safety and
electromagnetic compatibility requirements.
The EVGS user interface incorporates touch-screen operation and optional voice-control
functionality. The system provides a secure connection between the catheter and
console that supports substantially equivalent imaging performance and does not
change the intended use or risk profile.
The predicate device includes additional functionality and broader indications not
present in the EVGS, including Fractional Flow Reserve (FFR), Diastolic hyperemia-Free
Ratio (DFR), and automatic pullback functionality. EVGS does not provide FFR, DFR, or
automatic pullback capabilities. In addition, the Evident Peripheral Imaging Catheters are
indicated for ultrasound examination of peripheral vascular pathology only.
These differences represent a narrowing of the subject device's functionality and
catheter indications relative to the predicate and do not raise different questions of safety
or effectiveness as the EVGS retains the same fundamental IVUS imaging technology,
operating principles, and intended diagnostic purpose while excluding these additional
functions.
The Evident imaging catheters and the reference catheters use similar intravascular
ultrasound technology and share comparable fundamental design characteristics. The
catheters are provided sterile and meet biocompatibility requirements for
limited-exposure, blood-contacting devices.
Differences between the subject and reference catheters relate to implementation details
that do not affect the fundamental operating principle, intended use, or performance
characteristics. These differences do not raise new or different questions of safety or
effectiveness.

Conclusion: 807.92(b)(3)

validation, the Evident Vascular™ Guidance System (EVGS) is substantially equivalent

does not raise new or different questions of safety or effectiveness.
